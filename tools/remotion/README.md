# Remotion (animated captions, titles, enhancers)
- Free licence covers individuals and for-profit organisations with up to 3 employees (checked 4 Nov 2026, Remotion 4.0.540). Re-check if the clinic grows past that.
- Setup in Claude's sandbox: `npm install` here, then `node render.mjs`. Uses the pre-installed Playwright headless_shell (/opt/pw-browsers/chromium_headless_shell-*/chrome-linux/headless_shell) because Remotion's own browser download is blocked.
- src/Captions.jsx = first test: name/MMC band slides in (first 2 s), Hindi words pop in one by one with the spoken word in gold, English line under it. Brand colours navy #0D2C5C, green #62AA94, gold #E6AD3C, mint #E0F1EC.
- Laptop folder for the workflow: Downloads\BJ_Video_Editor\{Raw,References,Render}.
